# LOUNGE · 테일즈런너 Lv.15 길드 홈페이지

프리미엄 라운지 콘셉트로 제작된 **순수 HTML / CSS / JavaScript** 정적 사이트입니다. 프레임워크나 서버, 빌드 과정 없이 GitHub Pages에 게시할 수 있습니다.

## 빠른 시작

1. ZIP 파일을 **모두 압축 해제**합니다.
2. 폴더 안의 `index.html`을 열어 첫 화면을 확인합니다.
3. 필요한 내용은 `index.html`에서 직접 수정합니다.
4. GitHub에 새 공개 저장소를 만들고, 이 폴더의 파일을 **루트**에 업로드합니다. (`index.html`, `assets` 폴더, `manifest.webmanifest`)
5. GitHub의 **Settings → Pages → Build and deployment → Deploy from a branch → main / (root)** 를 선택하고 저장합니다.
6. Pages에 게시된 주소로 접속해 확인합니다. GitHub 배포가 완료되기까지 잠시 지연될 수 있습니다.

> GitHub에 업로드할 때 ZIP 파일만 올리면 홈페이지가 열리지 않습니다. 반드시 **압축을 푼 파일들을** 업로드하세요.

## 페이지 기능

- 매번 홈페이지를 열면 나타나는 시네마틱 입장 화면, **노래와 함께 입장 / 조용히 입장** 두 가지 선택
- 배경음악 **JENNIE — like JENNIE** (사용자가 제공한 MP3, 페이지의 `assets/lounge-like-jennie.mp3`에 포함)
- **노래와 함께 입장** 누르면 다음 화면으로 전환하며 음악 재생 시작 및 반복 재생
- **조용히 입장** 누르면 무음 입장, 나중에 음악 플레이어로 직접 켜기 가능
- 처음 권장 음량 **18%**, 입장 화면 및 좌측 아래 미니 음악 플레이어에서 0~100% 조절 가능 (현재 설정 기억)
- 페이지 방문만으로 음악을 재생하지 않음. 브라우저 자동재생 정책에 맞춰 사용자 클릭에만 재생
- 미드나이트 ↔ 샴페인 테마 변경, 선택 저장
- PC / 모바일 반응형 내비게이션, 스크롤 진행 표시와 맨 위로 이동
- 가입 요건 **자가 체크** 4개 (저장/전송 안 함)
- 길드 규칙 12개, 범주별 필터 및 키워드 검색 / 전체 펼치기
- 가입 문의 양식 입력 → 라이브 미리보기 → 내용 복사
- 운영진 닉네임/디스코드 아이디 원클릭 복사
- 길드 오픈채팅 비밀번호 보기 / 숨기기 / 복사
- 방문 기념 카드 닉네임 변경 및 **PNG 다운로드** (가입 증명용 아님)
- 페이지에서 입력창 밖을 클릭한 후 키보드로 **`a` `s` `a`** 를 순서대로 누르면 `잘부탁드립니다!` 이스터에그
- `prefers-reduced-motion`을 존중하는 애니메이션 및 키보드 접근성

## 디자인·운영 참고 사항

- `index.html` — 콘텐츠 / 문구 / 링크 / 기본 HTML
- `assets/styles.css` — 디자인, 테마, 반응형, 모션
- `assets/main.js` — 입장, 검색, 복사, 문의 생성, 이미지 저장, 이스터에그
- `assets/lounge-like-jennie.mp3` — 사용자가 제공한 음악 (파일을 빼면 플레이어에서 재생되지 않음)
- `assets/lounge-portal.svg` — 직접 그린 황금 아치 메인 일러스트
- `assets/monogram.svg` / `assets/favicon.svg` — L 엠블럼, 파비콘
- `manifest.webmanifest` — 웹앱 이름 및 테마 색상
